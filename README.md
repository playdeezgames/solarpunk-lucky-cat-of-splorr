# Composters of SPLORR!!

An entry for [Jamference: AI Game Jam Hack 4](https://itch.io/jam/jamference-ai-game-jam-hack-4) (theme Solarpunk, restriction Hidden Lucky Cat). You run the street's compost bin: steer the neighbours' scraps so greens touch browns and rot into compost, then spend the compost to turn a grey street into a solarpunk one. Odin compiled to WebAssembly.

Made by an AI agent (Claude Code) at TheGrumpyGameDev's direction. Font: DINOBYTE by mby (CC BY 4.0).

See `DESIGN.md` for the design and `CLAUDE.md` for building.
